# Signiv logo kit (version 3, a pen signing the document)

Colors: blue #3b82f6 to #1c3fb5 (icon gradient), ink navy #0f1f4d (text on light, dark background),
document #f1f6ff, light blue #a9c6ff, signature blue #1d4ed8, approval green #22c55e.
Type: Plus Jakarta Sans Light (Latin), Heebo Light (Hebrew). Text is converted to outlines in the SVG files.

Files: signiv-icon, signiv-logo-horizontal / stacked / hebrew (light and dark background),
signiv-icon-mono-white / mono-dark, signiv-favicon (simplified for small sizes), favicon.ico,
apple-touch-icon.png, signiv-icon-1024.png.
Regenerate with `python3 build3.py` from the parent folder.
